# Catalogue Frsource — GitHub Pages

Cette version contient **4032 notices** provenant de `Frsource.xlsx`.

## Fichiers

- `index.html` — page du catalogue
- `style.css` — mise en page
- `script.js` — recherche, pagination et liens cliquables
- `data.csv` — données publiques

## Fonctionnalités

- Recherche par titre, auteur, sujet, région et période
- Bouton **Rechercher** et recherche avec la touche Entrée
- Bouton **Réinitialiser**
- Auteurs individuels et collectifs cliquables
- Régions cliquables
- Sujets cliquables
- Pagination compacte
- Les valeurs séparées par `|` sont traitées comme plusieurs options
